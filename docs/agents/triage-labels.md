# Triage 標籤

各 skill 用五個標準 triage 角色描述 issue 狀態。這個檔案把這些角色對應到本 repo issue tracker 實際使用的標籤字串。

| mattpocock/skills 的標籤 | 本 repo 的標籤    | 意思                                   |
| ------------------------ | ----------------- | -------------------------------------- |
| `needs-triage`           | `needs-triage`    | 還沒評估過這張 issue                   |
| `needs-info`             | `needs-info`      | 等回報的人補資訊                       |
| `ready-for-agent`        | `ready-for-agent` | 規格已經寫清楚,可以交給 AI agent 自己做 |
| `ready-for-human`        | `ready-for-human` | 需要人自己動手做                       |
| `wontfix`                | `wontfix`         | 決定不處理                             |

skill 提到某個角色時(例如「套上 AFK-ready 的 triage 標籤」),使用上表對應的標籤字串。

要改用其他名稱時,只改右邊那一欄。
